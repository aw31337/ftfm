# DFIR Go-Bag Checklist

> FTFM Template | Section 2 — Preservation  
> Source: Forensic Team Field Manual (FTFM) — https://www.amazon.com/dp/B0F6KD9XJM

Print and laminate. Check before every deployment. Replace consumables after each case.

---

## Computing

- [ ] War Laptop #1 (primary)
- [ ] War Laptop #2 (backup)
- [ ] Portable KVM — keyboard, mouse, portable monitor
- [ ] Mobile Hotspot (charged, SIM active)
- [ ] Bootable USB/disk devices (forensic OS: SIFT, Kali, TAILS, WinFE)

---

## Networking

- [ ] CAT5/6 cables — 1m, 3m, 10m, 30m
- [ ] Cable couplers (Cat6 inline)
- [ ] Crossover cable + coupler
- [ ] Taps / hub / mini switch (for passive capture)
- [ ] Fiber adapters: FC, LC, FDDI, SC, ST
- [ ] Media converter (fiber ↔ copper)

---

## Cables & Adapters

- [ ] USB-A / USB-B / USB-C / USB 3.0 / mini / micro
- [ ] Firewire cable (400 + 800)
- [ ] HDMI / VGA / DVI video cables
- [ ] SATA interface cable
- [ ] IDE cables (8" and 2")
- [ ] SCSI-3 interface cable
- [ ] 1.8" / 2.5" hard drive adapters
- [ ] ZIF hard drive adapter
- [ ] MicroSATA adapter
- [ ] eSATA to eSATA cable
- [ ] Legacy adapters (ATA, IDE, SCSI, SAS, NGFF, Thunderbolt, PCIe)
